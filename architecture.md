## Learning Outcomes

*Transcribed from the per-chapter outcomes in TIKTOC.md. At least one Apply+ per chapter.*

### Chapter 0 — Probability Foundations
1. (Remember) State the definition of conditional probability P(A|B)
2. (Apply) Compute P(A|B) from a joint probability table
3. (Apply) Apply Bayes' theorem to a two-hypothesis problem by hand
4. (Understand) Explain why P(A|B) ≠ P(B|A)

### Chapter 1 — The Same Question, Two Answers
1. (Understand) Explain what a p-value does and does not say
2. (Analyze) Identify the question frequentist NHST cannot answer about a single patient's diagnosis
3. (Apply) Compute a posterior probability via Bayes' theorem for a two-hypothesis diagnostic problem
4. (Evaluate) Compare what each approach tells the clinician and what each leaves unanswered

### Chapter 2 — Prompting for Statistics
1. (Apply) Prompt an LLM to implement a two-hypothesis Bayesian problem and verify against hand calculation
2. (Analyze) Identify when an LLM's statistical output is wrong by checking it against problem structure
3. (Apply) Prompt for both frequentist and Bayesian solutions to the same problem and compare
4. (Create) Write a problem description precise enough that an LLM produces correct, verifiable code first try

### Chapter 3 — Counting and Estimating
1. (Apply) Construct a frequentist confidence interval for a proportion
2. (Apply) Build a Beta-Binomial model and compute a credible interval
3. (Analyze) Explain the difference between what a CI and a credible interval claim
4. (Evaluate) Assess when each approach is more useful for a quality-control decision

### Chapter 4 — Comparing Two Groups
1. (Apply) Run and interpret a two-sample t-test
2. (Apply) Build a Bayesian two-group comparison with posteriors on both means
3. (Analyze) Explain the replication crisis as a consequence of ignoring priors (Ioannidis)
4. (Evaluate) Assess what "statistically significant" does and does not establish

### Chapter 5 — Regression, Both Ways
1. (Apply) Fit and interpret a frequentist linear regression
2. (Apply) Specify and fit a Bayesian linear regression with priors on slope and intercept
3. (Analyze) Explain a posterior predictive distribution and why it beats a prediction interval for decisions
4. (Evaluate) Assess the practical implications of both approaches for a budget recommendation

### Chapter 6 — Model Comparison
1. (Apply) Compare two models using AIC and a likelihood-ratio test
2. (Apply) Compute a Bayes factor comparing two models
3. (Analyze) Explain what AIC measures vs. what a Bayes factor measures
4. (Evaluate) Assess when model comparison gives a clear answer and what to do when it doesn't

### Chapter 7 — Priors
1. (Analyze) Identify the implicit prior assumptions in a standard frequentist t-test
2. (Apply) Run the same Bayesian analysis under three priors and document what changes
3. (Evaluate) Defend a prior choice using domain knowledge, pilot data, or principled ignorance
4. (Evaluate) Assess when prior sensitivity matters and when it doesn't

### Chapter 8 — When Data Is Sparse
1. (Apply) Identify when standard frequentist methods are unreliable for sparse data
2. (Apply) Use informative priors to stabilize Bayesian estimates in small samples
3. (Analyze) Explain why significant effects in underpowered studies are systematically too large (winner's curse)
4. (Evaluate) Assess the tradeoff between waiting for more data and acting on sparse evidence

### Chapter 9 — Hierarchical Problems
1. (Understand) Explain the partial-pooling problem and why it needs a hierarchical model
2. (Apply) Fit a frequentist mixed-effects model for grouped data
3. (Apply) Specify and interpret a Bayesian hierarchical model
4. (Analyze) Compare complete pooling, no pooling, and partial pooling
5. (Evaluate) Assess when the added complexity of a Bayesian hierarchical model is worth the cost

### Chapter 10 — Time and Sequence
1. (Apply) Fit a frequentist ARIMA model and produce a point forecast
2. (Apply) Build a Bayesian structural time-series model with sequential updating
3. (Analyze) Explain sequential updating as a natural consequence of Bayesian inference
4. (Evaluate) Assess the value of a predictive distribution vs. a point forecast for inventory decisions

### Chapter 11 — Classification and Decision
1. (Apply) Fit frequentist logistic regression and interpret it as a classification model
2. (Apply) Build Bayesian logistic regression with posterior predictive classification
3. (Analyze) Explain what loss function a given classification threshold implies
4. (Evaluate) Assess the decision-theoretic implications of threshold choices under asymmetric costs

### Chapter 12 — A Real Problem, Both Ways
1. (Apply) Conduct a complete frequentist analysis of a self-selected real dataset
2. (Apply) Conduct a complete Bayesian analysis of the same dataset
3. (Evaluate) Compare both analyses — where they agree, diverge, and why
4. (Create) Produce a written methodological justification for a preferred approach

### Chapter 13 — Choosing
1. (Analyze) Identify decision factors that favor frequentist methods for a given problem
2. (Analyze) Identify decision factors that favor Bayesian methods for a given problem
3. (Evaluate) Apply a structured decision framework to method selection for novel problems
4. (Create) Write a methodological justification that would satisfy a skeptical reviewer

## Sequencing Model and Justification

**Primary model:** [x] Concrete→Abstract and [x] Problem→Solution, layered over a [x] Spiral return.
[INFERRED FROM: every chapter opens with a concrete problem before theory; the frequentist↔Bayesian comparison recurs each chapter at rising complexity.]

**Justification against learner profile:** the reader already has frequentist
exposure but reflexive habits. Opening each chapter with a concrete decision a
practitioner faces (and the frequentist answer first) meets them where they are,
then exposes the gap the Bayesian approach fills — the most reliable route to
changing an entrenched default.

**Spiral escalation:** the comparison is the spiral. It returns every chapter
and must escalate — Ch 1 two-hypothesis arithmetic → Ch 3 conjugate estimation
→ Ch 5 regression/predictive distributions → Ch 7 priors made explicit → Ch 9
full hierarchical posteriors. The **asymmetry rule** (more space on the Bayesian
side from Ch 5 on) is the visible escalation marker; it is named, not silent.

**Most likely break-down chapter:** Chapter 9 (Hierarchical Problems) — the
complexity spike. Flagged in the TOC with an opening asymmetry notice.

**Transition chapter (foundation→advanced pivot):** Chapter 5 (Regression),
where the Bayesian solution first returns answers the frequentist one
structurally cannot, and where the asymmetry is first named.

## Three-Act Learning Arc

**Act One — Establish (Ch 0–4):** the two paradigms answer different questions.
- Inciting question: a positive rare-disease test is 99% accurate — does the patient have the disease? (No.)
- End of Act One: the reader can run and interpret both a frequentist and a Bayesian analysis of simple, well-specified problems and state what each leaves unanswered.

**Act Two — Build (Ch 5–9):** the methods where the divergence carries decision weight.
- Hardest conceptual moment: Bayesian hierarchical models and partial pooling (Ch 9).
- End of Act Two: the reader can specify priors, compare models, and handle sparse and grouped data — and can say what the Bayesian complexity buys.

**Act Three — Apply (Ch 10–13):** sequence, decision, synthesis, judgment.
- Synthesis project: Ch 12 capstone — both frameworks on one self-chosen real dataset.
- End of Act Three: the reader produces a written, defensible method choice for a real problem.

**Transition (Act One → Act Two):** the student can solve a simple problem both
ways and articulate what each cannot answer.

**Transition (Act Two → Act Three):** the student can make the modeling choices
(priors, model comparison, sparse/grouped handling) the capstone requires.

**Arc statement:** "This book takes the reader from *applying a default
statistical method* to *choosing a method deliberately* by first **showing the
same question answered two ways**, then **building the methods where the choice
has consequences**, then **handing the reader a real dataset and a framework for
choosing**."

## Front-Loading Decisions

Conditional probability and Bayes' theorem (rated NOT SAFE) are front-loaded
into **Chapter 0** as a prerequisite resolver, kept out of the 13-chapter
semester budget. Programming ability is deliberately *not* assumed — it is
resolved by teaching LLM-assisted implementation in **Chapter 2** rather than
by a coding prerequisite. Distribution-specific background (Beta, normal,
binomial) is embedded at first use per chapter rather than gathered into a
foundations chapter, since each is needed only locally.
